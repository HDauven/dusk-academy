    How the lessons run
    The contract lessons also have a browser simulator for a limited Rust subset. It interprets the editor’s source and labels its results and progress as simulated. It is not a compiler or DuskVM. The following describes the separate native setup.
    The local server compiles your Forge contract to WebAssembly, then deploys and calls it in DuskVM. Compilation and execution run in separate sandboxes.
    Each run starts with a new deployment. Calls on that deployment share state. Editing this file does not upgrade a live blockchain contract.
    The tests count contract panics as rejections. Gas exhaustion and ABI errors fail the run. Later scenarios use fixed local caller and venue contracts. These test fixtures are not authenticated wallets or production services.
    The last checkpoint also builds the matching data-driver and checks its method ABI with Dusk Connect in a separate sandbox.
    Everything runs locally. No wallet, network transaction or cryptographic proof is involved.
    Dusk Academy is an independent learning project, not an official Dusk product.
